# Выпуск с Mac владельца (GitHub Actions не используются)

Решение владельца 2026-10-19: оплаты GitHub не будет, Actions не запускаются. Загрузка файлов в релизы через `gh` оплаты не требует, поэтому всё, что делал CI, делается здесь. Ключи: `~/Lullaby-keys/lullaby-release.key` (манифесты, мосты, каталог, сигнатуры) и `lullaby-sparkle.key` (обновления приложения). Секретные части никуда не копируются и в журналы не попадают.

## Мост для нового релиза Dormison (например `dormison-r7`)

1. Собрать, проверить в Wine и подписать **своим** ключом, ничего не отправляя:
   ```
   cd ~/Projects/NotProton
   CHANNEL=stable RELEASE_KEY=~/Lullaby-keys/lullaby-release.key \
     FEED_BASE=https://github.com/Ruslan-Ukraina/Lullaby/releases/download/ release/local-bridge.sh
   ```
   Это скачивает движок (проверка подписи Dormison и хешей), собирает дерево Wine на его коммите, B1 `ntdll`, патчи движка (`patches/engine/patches/`, без `experiments/`), `lsteamclient` и `steam.exe`, тест хука в Wine (x86_64 и i386, плюс контроль), упаковывает и подписывает. Итог в `scratch/local-bridge/<движок>/feed/`.
2. Посмотреть, что будет загружено (ничего не отправляется):
   ```
   release/local-publish.sh dormison-r7 1
   ```
3. Только после проверки и твоего решения загрузить: `release/local-publish.sh dormison-r7 1 --yes`.

Порядок загрузки: сначала мост, потом манифест (приложение никогда не увидит манифест с несуществующим файлом). Репозиторий приватный: приложение читает релизы с токеном из Keychain (`docs/RELEASING.md`, раздел про токен).

## Каталог исправлений игр, сигнатуры Steam, приложение

Такой же порядок (собрать → подписать ключом → проверить → загрузить). Для каталога: файл `game-fixes.json` с целым `serial` подписывается `swift release/sign.swift <ключ> game-fixes.json` и загружается в релиз `manifest`. Скрипты для сигнатур (`release/steam-signatures.sh`) и приложения (`make app`, Sparkle) пока рассчитаны на CI; локальные версии будут добавлены по мере надобности.

## Что агент делает и не делает

Собирает, тестирует, подписывает и **готовит** выпуск; загружает (`--yes`) только после твоего слова.
