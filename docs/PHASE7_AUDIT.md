| Пункт | Статус | Факты |
|---|---|---|
| Отдельная папка рендерера, закреплённый релиз, загрузка при выборе, M3+/macOS 15+, только 64-бит, LGPL (лицензии + `SOURCE.txt`, `NOTICE`) | ✅ | P7C-1…3, suite `Mullion store`; живьём: PEAK 83,8 FPS (DXMT 89,6); **RE9 (D3D12) — чёрное окно, 0 кадров** — оставлен экспериментом (PROGRESS 10.10) |

Факты (README, релиз, проверено 10.10): v0.1-pre1 (05.10.2026, pre-release, `mullion-v0.1-pre1.tar.gz`, 13,9 МБ, sha256 `f5c92561…a5be43f`); LGPL-2.1+ (`LICENSE`; `LICENSE.OLD` — старая лицензия DXMT для кода до апреля 2026); D3D10/11/12 на Metal, форк DXMT `7c8dee1`; требования — M3+ (твой M4 Pro подходит), macOS 15+, x86_64 Wine, только 64-битные игры; архив в раскладке DXMT (`x86_64-windows`, `x86_64-unix`); штатный `install.sh` **заменяет Direct3D Wine** — нам нельзя. Сборка: Meson ≥ 1.3, Xcode с Metal, LLVM 15 static x86_64, llvm-mingw, дерево сборки Wine.

Как подключать (план ROADMAP §7, сверено с нашим механизмом рендереров): отдельная папка `renderers/mullion/` с `x86_64-windows/*.dll` и `x86_64-unix/winemetal.so` Mullion через `WINEDLLPATH_PREPEND` (как D3DMetal), `winemetal.dll` Mullion — в `system32` префикса только при этом рендерере (DXMT кладёт свою при своём запуске); версия и sha256 закреплены, обновление — семейство компонента `mullion` в нашем подписанном манифесте; строка только при M3+ и macOS 15+, по умолчанию выключен, пометка «эксперимент»; `NOTICE`/credits. Риски: `winemetal.so` Mullion собран под другой Wine — проверить совместимость с Dormison b2; распространение бинарников LGPL требует исходников (у Mullion публичные — ссылка на тег).
Приёмка: RE9 на Mullion и на D3DMetal до меню, FPS в одинаковых настройках (чередованием).
