# Полный экран и «чёлка» MacBook — что выяснено (2026-10-17)

Записано по просьбе владельца, чтобы подумать. Опыты — на RE9 (D3DMetal, GPTK 4.0b3,
MacBook Pro M4 Pro, экран 3024×1964 пикселей = 1512×982 точек, 120 Гц).

## Коротко

- **Нативный полноэкранный режим macOS (зелёная кнопка, Ctrl+Cmd+F) область под «чёлкой» не
  отдаёт никогда.** Окно в нём — 1512×949 точек = 3024×1898 пикселей, полоса сверху чёрная.
  Так устроен AppKit для всех приложений; ключ `NSPrefersDisplaySafeAreaCompatibilityMode`
  этого не меняет (он только про режим совместимости старых приложений).
- **Весь экран вместе с «чёлкой» (3024×1964) занимает только окно без рамки размером с экран
  при скрытой строке меню.** Это не нативный полноэкранный режим, а обычное окно поверх всего.
  Так работает режим RE9 «Borderless» под Wine уже сейчас: окно 1512×982 точек от (0,0).
  Сторонние утилиты делают то же самое у любых программ: стиль окна «без рамки», рамка окна =
  `screen.frame`, `NSApplicationPresentationAutoHideMenuBar | AutoHideDock`
  (https://notes.alinpanaitiu.com/Fullscreen-apps-above-the-MacBook-notch).
- **«Чёлка» не причина «Composited».** Опыт: окно на весь дисплей 3024×1964, слой Metal
  непрозрачный, размеры совпадают, HDR выключен — всё равно Composited. Причина в слоях
  окна Wine, которые лежат под картинкой игры (см. ниже).

## Что делал Lullaby в опытах

| Опыт | Окно | Кадр игры | HUD |
|---|---|---|---|
| RE9 «Borderless» как есть | 1512×982 точек, весь экран | 3024×1964 | Composited |
| Нативный полноэкранный (патч 0004 включает сам при старте) | 1512×949, под «чёлкой» | 3024×1898 (игра сама подстроилась) | Composited |
| Тот же + слой непрозрачный, без HDR | 1512×949 | 3024×1898 | Composited |
| Окно без рамки на весь дисплей + слой непрозрачный, без HDR | 1512×982 | 3024×1964 | Composited |

Попутно найдено: RE9 в режиме «FullScreen» берёт `FullScreenDisplayMode=94` = 2294×1432 @ 120 Гц
(«1440» с рамками). Родной 3024×1964 @ 120 — режим 130 в её списке. Менять `config.ini` игры
Lullaby без разрешения владельца не будет.

## Варианты на подумать

1. **Нативный полноэкранный, под «чёлкой»** — привычно для macOS (жесты, отдельный рабочий стол),
   игра сама рисует 3024×1898, полоса сверху чёрная.
2. **Окно без рамки на весь дисплей вместе с «чёлкой»** — картинка до самого верха, «чёлка»
   закрывает её середину сверху; нет отдельного рабочего стола macOS. RE9 рисует 16:9 и сама
   ставит чёрные полосы сверху/снизу, так что под «чёлкой» у неё всё равно чёрное.
3. Переключатель в «Додаткові налаштування» с выбором 1 или 2.

Прямой вывод на экран (Direct) — отдельная задача про слои окна Wine (WoWSilicon/WoWSilicon#25):
над слоем Metal лежат слои окна с цветом фона и картинкой поверхности Wine, macOS их
смешивает. Lullaby проверяет очистку этих слоёв (патч `winemac.so` 0004, эксперимент).
