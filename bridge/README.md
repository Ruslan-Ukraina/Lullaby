# bridge
The Steam bridge: `lsteamclient/` (lby-applejack-steambridge, from Proton, Steamworks SDK License) and `steam-shim/` (lby-bigmack-steamexe, `steam.exe`, BSD-3-Clause), plus the scripts that build them against the engine's own source tree and `bridge-manifest.json` (engine <-> bridge compatibility).
Not here: patches to engine modules (see `patches/`). Every element needs a recorded reason.
