# lby-rarity-icons

Game icons in Lullaby's look (macOS body shape and glass rim traced from the system's rendering of Lullaby's icon; a logo on a transparent background set on a solid fill of its main colour). The real files live in `app/helpers/` because the app's build makes the tool; the links here keep every Lullaby addition findable in `patches/`.
- `iconmaker.swift` -> `app/helpers/iconmaker.swift`
- `tests/` -> `app/helpers/tests/` (`make iconmaker-tests`)
